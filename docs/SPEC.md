## 1. 개요

### 1.1 목적

사고 싶은 물건을 마음껏 장바구니에 담고 **결제 버튼까지 누르는 경험**을 주어 대리만족을 준다.
실제로 돈은 나가지 않으며, 마지막에 "구조된 금액"(= 쓰지 않은 돈)을 보여주는 **구조 보고서**로 마무리한다.

### 1.2 핵심 컨셉

- 결제 = **구조 작전**. 사용자는 쇼핑을 끝까지 하고, 텅장구조대가 마지막 순간에 통장을 구한다.
- 실제 상품(네이버 쇼핑 검색 결과)을 써서 "진짜 사는 느낌"을 살린다.
- 쇼핑 화면은 익숙한 쇼핑몰 UI를 **패러디**하고, 시작(랜딩)과 끝(구조 보고서)만 다르게 만든다.

### 1.3 범위

| 포함 (MVP) | 제외 |
|---|---|
| 랜딩, 상품 리스트·검색, 장바구니, 가짜 결제, 구조 보고서 | 로그인·회원가입 |
| 네이버 쇼핑 검색 API 연동 (+ 키 없을 때 가짜 데이터) | 상품 상세 페이지 |
| 장바구니·주문을 브라우저(localStorage)에 저장 | 서버 DB (Supabase 등) |
| 배송 상태 연출 | 실제 결제·배송, 카드번호 입력 |
| | 사용자 링크 붙여넣기, 부동산(국토부 API) |

| S-03 | 상품 카드 | 썸네일, 브랜드, 상품명(2줄 말줄임), 최저가(₩, 천 단위 콤마) 표시. 썸네일 없으면 🛍️ 대체 이미지 | P0 |
| S-04 | 담기 | `담기` 클릭 시 장바구니에 추가. 이미 담긴 상품은 버튼이 `담김`(비활성)으로 바뀜. 같은 상품 중복 불가 | P0 |
| S-05 | 상태 표시 | 로딩 중 "찾는 중…", 에러 시 빨간 문구, 가짜 데이터일 때 노란 안내 박스 | P0 |
| S-06 | 담기 피드백 | 담을 때 토스트 "통장이 위험해요 🚨" | P1 |
| S-07 | 더보기 | 결과 하단 `더보기`로 다음 20개 추가 로드 (`start` 파라미터 추가 필요) | P2 |

### 3.3 장바구니 `/cart`

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| CA-01 | 목록 | 담은 상품의 썸네일·이름·가격 목록 | P0 |
| CA-02 | 삭제 | 항목별 `삭제` 버튼 | P0 |

### 3.4 결제 `/checkout`

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| CO-01 | 접근 제한 | 장바구니가 비어 있으면 `/cart`로 이동 | P0 |
| CO-02 | 주문 요약 | 상품 개수 + 상품명 나열(한 줄 말줄임) | P0 |
| CO-03 | 배송지 | 자유 텍스트 입력, 선택 사항. placeholder "예: 화성 올림푸스 산 정상" | P1 |
| CO-04 | 결제수단 | "🚑 구조페이 · 잔액 무제한 · 수수료 0원" 고정 표시 (선택 UI 없음) | P0 |
| CO-05 | 결제 | `구조페이로 ₩{총액} 결제하기` 클릭 → "구조대 출동 중… 🚑"(1.2초) → "통장 확보 완료 ✅"(0.8초) → 주문 저장 → 장바구니 비움 → `/done` 이동. 진행 중 버튼 비활성 | P0 |

**금지 사항:** 카드번호, 실명, 전화번호, 실제 주소 등 실제 결제처럼 보이는 입력란은 만들지 않는다.

### 3.5 구조 보고서 `/done`

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| D-01 | 구조 보고서 | 구조 번호(`TJ-YYYYMMDD-NNNN`), 구조 일시, 품목·가격, 결제한 금액 ₩0, **구조된 금액**(총액, 강조) | P0 |
| D-02 | 배송 상태 연출 | 3초마다 순환: 구조 물품 포장 중… → 평행세계 물류센터 도착 → 멀티유니버스의 나에게 배송 중… → 다른 차원의 나에게 전달 시도 중 → 배송 지연: 다음 생 | P1 |
| D-03 | 다시 쇼핑 | `다시 쇼핑하기` → `/shop` | P0 |
| D-04 | 기록 없음 | 저장된 주문이 없으면 "아직 구조된 기록이 없어요." + 쇼핑하러 가기 | P0 |
| D-05 | 캡처·공유 | 구조 보고서를 이미지로 저장 | P2 |

## 4. API 명세

### `GET /api/search`

네이버 쇼핑 검색 API(`https://openapi.naver.com/v1/search/shop.json`)를 서버에서 대신 호출한다.
브라우저에서 네이버를 직접 부르면 CORS에 막히고 키가 노출되므로 반드시 이 경로를 쓴다.

**요청**

| 파라미터 | 필수 | 설명 |
|---|---|---|
| `query` | ✅ | 검색어 |
| `display` | | 결과 개수, 1~100, 기본 20 |

**응답 200**

```json
{
  "source": "naver",
  "items": [
    {
      "id": "12345678",
      "title": "Apple 맥북 프로 14 M4",
      "link": "https://...",
      "image": "https://shopping-phinf.pstatic.net/...",
      "price": 2390000,
      "brand": "Apple",
      "mallName": "네이버",
      "category": "디지털/가전/노트북"
    }
  ]
}
```

| 동작 | 설명 |
|---|---|
| 데이터 가공 | 상품명의 `<b>` 태그·HTML 엔티티 제거, `lprice` 문자열 → 숫자, `brand` 없으면 `maker` → `mallName` 순으로 대체 |
| 키 없음 | `NAVER_CLIENT_ID`/`NAVER_CLIENT_SECRET` 미설정 시 가짜 상품 8개 반환, `source: "mock"` |
| 캐시 | 같은 검색어는 1시간 캐시 (네이버 일일 호출 한도 절약) |

**에러**

| 상태 | 조건 | 응답 |
|---|---|---|
| 400 | `query` 없음 | `{ "error": "query 파라미터가 필요해요" }` |
| 502 | 네이버 API 실패 | `{ "error": "네이버 쇼핑 API 호출에 실패했어요" }` |

## 5. 데이터

### 5.1 타입 (`lib/types.ts`)

```ts
type Product = {
  id: string;        // 네이버 productId
  title: string;
  link: string;
  image: string;     // 가짜 데이터는 ""
  price: number;     // 최저가(원)
  brand: string;
  mallName: string;
  category: string;
};

type Order = {
  id: string;        // TJ-20261114-0042
  createdAt: string; // ISO
  items: Product[];
  total: number;     // 구조된 금액
  address: string;
};
```

### 5.2 브라우저 저장소

| 키 | 값 | 쓰는 곳 |
|---|---|---|
| `tj-cart` | `Product[]` | `lib/cart.tsx` (`useCart()`) |
| `tj-last-order` | `Order` | `lib/order.ts` (결제 → 구조 보고서 전달) |

### 5.3 환경 변수

| 이름 | 설명 |
|---|---|
| `NAVER_CLIENT_ID` | 네이버 개발자센터 애플리케이션 Client ID |
| `NAVER_CLIENT_SECRET` | 같은 애플리케이션의 Client Secret |

- 로컬: `.env.local` (커밋 금지). 배포: Vercel 대시보드 → Settings → Environment Variables.
- `NEXT_PUBLIC_` 접두사를 붙이지 않는다 (브라우저에 노출됨).

## 7. 비기능 요구사항 · 규칙

- **브랜딩:** 네이버 로고, "네이버 쇼핑" 이름을 쓰지 않는다. 레이아웃·색감만 패러디.
- **안전:** 실제 결제처럼 보이는 입력란 금지. 랜딩에 "실제 결제·배송 없음" 안내 필수.
- **보안:** API 키는 서버(API Route)에서만 사용.
- **배포:** Vercel, `main` 브랜치 기준.
- **협업:** 각자 브랜치 → `main`으로 PR. 공용 파일(`lib/types.ts`, `lib/cart.tsx`, `lib/order.ts`, `app/layout.tsx`)은 바꾸기 전에 단톡에 공유.

## 9. 후순위 아이디어

- 물건 도착 컨셉 (일정 시간 후 "도착했지만 보이지 않음")
- 구조 보고서 이미지 저장·공유 (D-05)
- 오늘 모든 사용자가 구조한 총액 (서버 DB 필요 → Supabase)
- 사용자가 상품 링크를 직접 붙여넣어 담기
- "집 사고 싶으시다면…" 부동산 실거래가 API
